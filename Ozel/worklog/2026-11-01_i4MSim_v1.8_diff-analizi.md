# WORKLOG — 2026-11-01 (oturum: i4MSim diff analizi + v1.8)

**Görev:** i4MSim v1.7'nin NightTownFullpack/python27.dll simülasyon-sonucu (12.853 byte / 828 bölge
fark) analizi; hook-tespiti/false-positive sorusunun cevaplanması; v1.8 geliştirmesi; teslimat.

## Yapılan işler

### 1. Girdi analizi (i4msim_diff.rar)
- `simule_memory.txt` (x1, sim, base=1E000000, 2.588.672 byte) ve `dinamik_memory.txt`
  (x2, canlı, pid=18104, aynı base) bağımsız Python ayrıştırıcıyla yeniden okundu.
- Bağımsız byte-diff **12.853 / 2.588.672 (%0,4965), 828 bölge** — aracın raporuyla birebir doğrulandı.
- PE dekode: e_lfanew=0xE8, 3 bölüm (data0 EXEC rawsize=0 [packer], data1, .rsrc), ImageBase 1E000000.
- **data0 (KOD) = 0 fark, IAT/IMPORT = 0 fark, BASERELOC = 0 fark.** Tüm fark data1 + 1 header byte.
- 828 bölgenin align-4 word analizi: **799 bölge HPTR-ASLR** (heap→heap pointer),
  15 CNT, ~5 T2-STAT, 1 IMG→IMG (RVA 0x24B248 — tek gerçek init-tier statik sapması),
  1 PATH (host klasör stringi), 1 PKS header byte.
- **RVA 0x1F5 kök-nedeni:** data0.PointerToRawData (sim 0x400 ↔ canlı 0) — packer-kosmetik,
  loader kullanmaz, hook değil.

### 2. Soruların cevapları
- **Farkların kaynağı:** ~%99 ASLR-heap + runtime sayaç (Metin2'ye özgü değil, her process'te
  yapısal); ~%1 gerçek init-tier sapması (<100 byte). Detay: `analiz/i4msim_12853_byte_analizi.md`
- **Hook/false-positive:** 12853 gürültüsünün TAMAMI veri bölgesinde; kod bölgesi 0 gürültü.
  EXEC-only + pointer-hedef taramasıyla false positive yok. SimpleStringFlag tarzı hook senaryoları
  (kod-patch / ml_meth pointer / Python-level) kapsam tablosuyla ayrıştırıldı.
- **Sistem değerlendirmesi:** mimari doğru (gerçek loader + fedai process kanıtlı), hedef metrik
  "byte-%100" değil "KOD+IAT+RELOC %100" olmalı; EXE tarafına aynı hook-katmanı önerisi (v1.9).

### 3. i4MSim v1.8 (kod)
- Taban: v1.0 kaynak zip (konsol logundaki v1.7 özelliklerinin bir kısmı bu tabanda yoktu;
  v1.8 v1.0'dan türetildi).
- **KOMUT 4** (canlı kendi-gürültüsü), **KOMUT 8** (hook tarama: EXEC-diff + pointer hedef-denetimi
  + modül-dışı EXEC + modül listesi), **KOMUT 3 semantik sınıflandırma** (HPTR-ASLR/T2-STAT/CNT/
  PATH/PKS/VERI + LOADER-YAPISAL özet), **PKS whitelist** (0x1F5 artık alarm üretmez), yeni VERDICT.
- Derleme: zig c++ 0.13.0 `-target x86-windows-gnu` (projenin kendi toolchain'i), statik,
  32-bit PE — `i4MSim.exe` (480 KB). Kaynak+exe: `i4MSim_v1.8.zip`.
- Smoke: derleme temiz (yalnızca libunwind başlık-uyarları); wine yok, çalışma-zamanı testi
  kullanıcı makinesinde yapılacak (beklenen akış: 1 → 2 → 3 → 8).
